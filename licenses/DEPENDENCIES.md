# 의존성 라이선스 목록

Lof Audio 0.1.0-beta.4의 잠금 파일을 기준으로 작성했습니다.

npm은 package-lock.json의 전체 패키지(개발 도구·다른 플랫폼의 선택 패키지 포함), Cargo는 Windows x64 의존성 그래프(빌드 의존성 포함)를 기록합니다. 최종 실행 파일에 이 목록의 모든 패키지가 포함된다는 의미는 아닙니다. SPDX 표현식은 패키지의 선언을 유지합니다.

설치된 패키지에서 수집한 저작권·라이선스 고지 원문은 [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt)에 있습니다. 설치되지 않은 npm 선택 패키지는 잠금 파일의 선언과 원본 링크를 기록합니다. 원문 파일 수집은 모든 소스 파일의 개별 고지를 대체하지 않습니다.
