# Lof Audio

**Lof Audio**는 로컬 라이브러리 관리와 일괄 태그 편집, 실시간 싱크 가사를 갖춘 데스크탑 뮤직 플레이어입니다.

## 기술 스택 (API 키 불필요 / 오픈소스 구성)

| 영역 | 기술 / 크레이트 / API | 설명 |
| --- | --- | --- |
| 프레임워크 | **Tauri 2 + React + TypeScript + Vite** | 가볍고 빠른 네이티브 데스크탑 앱 & 멀티 윈도우 사이즈 제어 |
| 오디오 재생 엔진 | **`rodio` + `symphonia` + `libopus`** | MP3, FLAC, WAV, OGG, M4A/AAC, ALAC, OPUS 재생, 탐색(Seek), 배속, 볼륨 제어 |
| 태그 읽기·쓰기 | **`lofty`** | 단일 곡 및 다중 곡 태그 일괄 수정, 자동 트랙 번호, 파일명 패턴 추출, 앨범 아트 내장 |
| 로컬 음악 DB | **`rusqlite` (`bundled`)** | 폴더 스캔 인덱싱, 플레이리스트, 즐겨찾기, 가사 싱크 오프셋(`ms`) 영구 저장 |
| 실시간 싱크 가사 | **LRCLIB API** (`/api/get`, `/api/search`) | 알송 스타일 실시간 하이라이트 가사, 줄 클릭 시 구간 점프, `.lrc` 파일 저장 |
| 음원 메타데이터 | **MusicBrainz API** (`/ws/2/recording`) | API 키 없이 곡/아티스트 기반 음원 메타데이터 및 Release MBID 검색 |
| 앨범 아트 | **Cover Art Archive API** (`/release/{MBID}/front-500`) | 전면 앨범 커버 자동 다운로드 및 오디오 파일 태그 내장 |

## 주요 기능

1. **듀얼 UI 모드**
   - **데스크탑 모드 (`1380 × 860`)**: 3단 레이아웃(좌측 라이브러리/폴더 트리, 중앙 고밀도 다중 선택 테이블 & 앨범 그리드, 우측 싱크 가사·태그·메타데이터 인스펙터, 하단 알송 2줄 실시간 가사 리본 + 플레이어 바).
   - **플레이어 모드 (`420 × 790`)**: 스마트폰 앱 비율로 창 크기가 자동 축소되며, 다이나믹 블러 배경·대형 앨범 커버·미니/전체 싱크 가사·항상 위에 고정(Pin) 기능을 지원합니다.
2. **실시간 싱크 가사 (LRCLIB 연동)**
   - 현재 재생 위치에 맞춰 가사가 실시간 하이라이트 및 자동 스크롤됩니다.
   - 원하는 가사 줄을 클릭하면 해당 시간으로 즉시 탐색(Seek)합니다.
   - `-0.5s` / `-0.1s` / `+0.1s` / `+0.5s` 싱크 오프셋 미세 조절 및 `.lrc` 파일 저장을 지원합니다.
3. **태그 일괄 편집 & 파일명 패턴 추출 (`lofty`)**
   - 여러 곡을 `Ctrl`/`Shift`/체크박스로 선택한 뒤 아티스트, 앨범, 연도, 장르, 앨범 아트를 한 번에 일괄 저장할 수 있습니다.
   - **자동 트랙 번호 매기기 (`1..N`)** 및 **`%artist% - %title%` 파일명 패턴 추출**을 지원합니다.
4. **워크스페이스별 라이브러리**
   - 상단에서 워크스페이스를 만들고 음악 폴더를 추가하면, 선택한 워크스페이스의 곡·앨범·아티스트·플레이리스트만 표시됩니다.
   - 마지막 선택은 재실행 후 복원되며, 기존 라이브러리는 기본 워크스페이스에 보존됩니다.
   - 같은 폴더를 여러 워크스페이스에 연결할 수 있습니다. 폴더 연결 해제와 곡 제거는 현재 워크스페이스에만 적용되며 음악 파일은 삭제하지 않습니다.
5. **MCP / 로컬 API / 스킬**
   - 앱 실행 중 워크스페이스·음악 검색·재생·태그·가사·플레이리스트를 MCP와 같은 이름의 HTTP API 도구로 관리합니다.
   - **설정 → MCP / API**에서 연결 설정을 복사하거나 Lof Audio 스킬을 설치·업데이트할 수 있습니다. 표준입출력 MCP는 앱 실행 파일의 `--mcp` 모드를 사용하므로 Node.js를 따로 설치할 필요가 없습니다.
   - 태그·가사 수정은 `track_read`의 revision을 확인한 뒤 명시한 필드만 저장합니다. 연결과 호출 방법은 [API 안내](skills/lof-audio/references/api.md), 사용 절차는 [스킬](skills/lof-audio/SKILL.md)을 참고하세요.
6. **앨범 정보 조회**
   - 앨범을 연 뒤 **앨범 정보 조회**에서 발매판을 선택하면 전체 트랙의 제목·재생 시간으로 후보를 한 번에 연결합니다. 속성·태그 편집의 자동 정보 매칭 탭에서도 **앨범 조회**를 선택할 수 있습니다.
   - 곡별 메타데이터와 가사는 병렬로 조회하며, 최근 응답과 진행 중인 동일 요청은 공유합니다. 앨범 커버도 같은 발매판의 곡마다 다시 내려받지 않습니다.
7. **AI의 여러 출처 메타정보 편집**
   - AI가 웹·공식 발매 정보·독립 카탈로그 등 사용 가능한 출처를 대조하고, MCP로 필드별 근거와 수정안을 미리 확인한 뒤 요청한 메타정보만 저장합니다.
   - 출처가 충돌하거나 독립 근거가 부족한 필드는 보류합니다. URL·관측값·전후 태그·저장 결과를 DB 이력으로 남깁니다. [조사·편집 절차](skills/lof-audio/references/metadata-research.md)를 참고하세요.

## 실행 방법

Opus 디코더를 빌드하려면 CMake가 필요합니다. Windows에서는 Visual Studio에 포함된 CMake도 자동으로 찾습니다.

```bash
# 의존성 설치
npm install

# 개발 모드 실행 (Tauri 데스크탑 창 실행)
npm run tauri dev

# 프로덕션 빌드
npm run tauri build
```
